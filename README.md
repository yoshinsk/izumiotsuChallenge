# 泉大津チャレンジ エンジョイランキングシステム

走行結果CSVを読み込み、午前コース・午後コース・体験コースごとに、ゼッケン別の順位を全件表示するWindowsアプリです。

## ダウンロード

[最新版をダウンロード](https://github.com/yoshinsk/izumiotsuChallenge/releases/latest/download/izumiotsu-ranking-latest.exe)

インストーラーは不要です。ダウンロードしたexeをそのまま起動してください。アプリは最大化した状態で開きます。

## 操作

1. `選択` で走行結果CSVを指定します。CSVを画面へドラッグアンドドロップしても解析できます。
2. StartTime/FinishTimeで午前・午後を分ける場合は `時刻で自動判定` を押します。
3. 時刻で分けられない場合は、午前終了時点で `午前CSVとして登録` を押します。
4. 午後終了時点では、午前と午後が入った累積CSVを選び、`午後CSV(累積)として登録` を押します。
5. 体験コースは `体験コースゼッケン` の範囲指定で判定します。初期値は `900-999` です。
6. M付きゼッケンをランキングから外す場合は、`講師の走行を除外` をオンにします。
7. 左側を狭くしたい場合は `設定を隠す` を押します。戻す場合は `設定` を押します。
8. 順位項目は画面右側のタブで切り替えます。
9. 必要に応じて `ランキングExcelを保存` で全ランキングをExcelファイルに保存します。
10. 各リザルトをPDFで保存する場合は、各リスト左下の `PDFでダウンロード` を押します。
11. アプリを閉じる場合は、左下の `終了` を押します。

## 体験コースゼッケンの指定例

- `900-999`: 900番から999番までを体験コースにします。
- `900-950,980`: 900番から950番までと、980番を体験コースにします。
- `T*`: Tで始まるゼッケンを体験コースにします。

## 集計ルール

- ベスト走行: ゼッケンごとの最短 `TotalLapTime` を上位とします。表示は `LapTimeString` を使います。
- ワースト走行 & ベストとの差: ゼッケンごとの `最遅TotalLapTime - 最短TotalLapTime` が大きい順です。`MissCourseCount` はタイム比較に加算しません。
- ミスコース総数: `MissCourseCount + FourWheelOffCourseCount` を合算します。
- パイロンタッチ総数: `PylonTouchCount` を合算します。
- 脱輪総数: `TwoWheelOffCourseCount` を合算します。
- ミスコース総数、パイロンタッチ総数、脱輪総数は、集計結果が0のゼッケンを表示しません。

## PDFの表示名

- ベスト走行: 速さランキング
- ワースト走行 & ベストとの差: 成長した人？ランキング
- ミスコース総数: 慣熟推奨ランキング
- パイロンタッチ総数: パイロン破壊魔神ランキング
- 脱輪総数: 枠にハマらないランキング

PDFはA4縦で保存します。ヘッダー中央に `泉大津Challenge` と表示名を入れ、右下にロゴを配置します。フォントは同梱のNoto Sans JPを使用します。

## 開発

計測担当PCでの利用に、Python、.NET、Node.js、npmは不要です。

開発PCでビルドする場合のみ、Node.jsとnpmを使用します。

```powershell
npm install
npm run dist:win
```

生成物は `release` フォルダに作成されます。

## 検証

npm test
